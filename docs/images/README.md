# Documentation screenshots

These screenshots show the isolated local demo at the application revision recorded in [documentation status](../developing/documentation-status.md). Books, people, email addresses, and collection names are synthetic.

The browser viewport is 1280 by 800. The demo blocks outbound connections, so external fonts and fallback icon collections can be unavailable. The screenshots explain navigation and controls; they do not establish production typography or every theme's appearance.
